книжная полка

Твоя книжная статистика

Профиль чтения — объединение LiveLib и Hardcover. Оценки, даты прочтения и перечитывания; метадата книг — из Hardcover.

LL LiveLib Прочитанные книги, личные оценки и даты

LiveLib заблокировал сервер (403)

Скопируй заголовок Cookie из браузера, где livelib.ru открывается без блокировки: DevTools → Network → любой запрос → Request Headers → Cookie: __ddg1=…. Вставь строку целиком (можно без префикса «Cookie:»). Значение уходит на сервер и хранится только там — в этом браузере оно не сохраняется.

Публичный профиль. Импорт идёт страницами по 20 книг — около 2–3 минут на 1 200 книг.

Файл экспорта безопасный режим · без скрапинга

Выгрузи историю сервисом livelib-backup и загрузи файл сюда. Сервер только читает файл — ни одного запроса на livelib.ru не уходит, поэтому такой импорт не похож на автоматический доступ.

Как выгрузить файл: рекомендуемые настройки
  1. Открой livelib-backup и введи своё имя пользователя LiveLib.
  2. Страница: «Прочитал». «Не дочитал» — отдельным файлом (полка «Не дочитал»). «Читаю сейчас» и «Хочу прочитать» можно не выгружать: это планы, а не история чтения.
  3. Формат файла: json (компактнее и точнее; csv тоже принимается).
  4. Колонки: Название, Автор, Дата прочтения, Моя оценка, ISBN, Жанры, Издатель, Дата издания, Язык, Серия, Ссылка на книгу, Ссылка на обложку.
  5. Не нужны: Общая оценка, счётчики лайков/рецензий/цитат/прочтений, Аннотация — они не влияют на статистику.

Даты в выгрузке — месяц и год: такие книги попадают в таймлайн по месяцу, но не в календарь и стрики. Повторная загрузка того же файла ничего не дублирует, а уже импортированные с сайта даты не затираются.

HC Hardcover Журнал чтения, оценки, даты, перечитывания

Использует API-токен владельца. ID можно взять из ссылки профиля; если профиль уже импортирован на сервере, он подставится из активного книжного профиля.

Можно подключить оба источника — профиль объединится, события не склеиваются. Повторный импорт обновляет данные источника.
